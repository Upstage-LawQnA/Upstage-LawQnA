# 별표 3 전용면적 85제곱미터 초과 장기전세주택의 다자녀 우선공급 입주자 자격 및 선정기준(제3조제4항제2호 관련)

[별표 3] <개정 2023. 8. 10.>

전용면적 85제곱미터 초과 장기전세주택의 다자녀 우선공급 입주자 자격 및 선정기준

# (제3조제4항제2호 관련)

| 구 분 | 선 정 기 준 |
| --- | --- |
| 청약자격 | ① 서울특별시 거주 ② 무주택세대구성원 |
| 선정순위 | ∘ 제1순위 입주자모집공고일 현재 「민법」상 미성년 자녀 수 3명 이상의 자 녀를 둔 무주택세대구성원 |
| 소득기준 | ∘ 제3조 적용 |
| 자산기준 | ∘「공공주택 특별법 시행규칙」 제13조제3항 및 「공공주택 입주자 보유 자산 관련 업무처리기준」 적용 |
| 입주자저축 | ∘ 해당 없음 |
| 선정기준 | 1. 자녀 수가 많은 사람 2. 무주택기간이 오래된 사람 3. 제1호 및 제2호가 같은 경우 추첨으로 선정된 사람 |
| 기 타 | 입주자를 선정하고 남은 주택이 있을 경우에는 미성년 3자녀 이상 특별공급 신청자를 대상으로 선정 |
