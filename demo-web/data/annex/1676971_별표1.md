# 별표 1 시내버스 운송수입금 탈루행위의 금액별 포상금 지급기준(제8조 제1항 관련)

[별표 1]

시내버스 운송수입금 탈루행위의 금액별 포상금 지급기준
(제8조 제1항 관련)

| 시내버스 운송수입금 탈루금액(천원) | 포상금 지급액(천원) |
| --- | --- |
| 500미만 | 500 |
| 500이상 ～ 1,000미만 | 1,000 |
| 1,000이상 ～ 1,500미만 | 1,500 |
| 1,500이상 ～ 2,000미만 | 2,000 |
| 2,000이상 ～ 2,500미만 | 2,500 |
| 2,500이상 ～ 3,000미만 | 3,000 |
| 3,000이상인 경우 | 포상금 지급심의 위원회에서 결정한 금액에 따른다. |
