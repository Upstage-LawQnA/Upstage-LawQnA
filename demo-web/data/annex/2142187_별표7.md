# [별표 7]

# 부설주차장의 부지인근 설치대상 범위(제23조 관련)

| 구 분 | 범 위 |
| --- | --- |
| “가” 지역 | ∘ 해당 부지의 경계선으로부터 부설주차장의 경계선 까지의 직선거리 150미터 이내 또는 도보거리 300 미터 이내 |
| “나” 지역 | ∘ 해당 부지의 경계선으로부터 부설주차장의 경계선 까지의 직선거리 300미터 이내 또는 도보거리 600 미터 이내 |


# 비 고

∘ 설치기준의 지역별 적용구분은 다음과 같다.

| 가. | “가”지역 : | 제주시 행정동 설치구역 |
| --- | --- | --- |
| 나. | “나”지역 : | “가”지역 이외의 구역 |
