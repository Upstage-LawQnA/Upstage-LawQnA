# ○ 통신구 조건

- - 통신구 행거설치 가능 단수 : 5단
- - 통신구 현재 행거사용 단수 : 4단
- - 통신구 가용 단수 : 1단


# ○ 신규점용자 조건

- 통신구 가용 단수 신규점용 : 1단

※ 신규 점용자가 가용단수(1단) 전체를 점용하지 않더라도 가용단수
1단을 사용하는 것으로 간주하고,
가용단수 1단에 제2, 제3의 수용가능한 여러 신규 점용의 경우는
가용단수 1단의 범위내에서 수용기관별로 균등배분하여 점용면적 산정

# ○ 전용면적 재산정 예시

- - 통신구 전용면적 (0.58㎡) × 4/5 = 0.46㎡
- - 신규점용자 전용면적 (0.58㎡) × 1/5 = 0.12㎡
