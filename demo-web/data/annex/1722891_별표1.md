# 폐기물 무단투기행위 신고 포상금 지급기준(제2조 관련)

(단위 : 만원)

| 무 단 투 기 행 위 신 고 대 상 | 포상금 |
| --- | --- |
| 1. 폐기물의 수집장소‧설비 또는 허가‧승인받은 매립시설 외의 곳에 생활 폐기물을 버리는 행위(매립, 소각 포함)를 한 자(법 제8조제1항 또는 제2항) 가. 별도기구 없이 휴대하고 있는 폐기물(담배꽁초, 껌, 휴지 등)을 버 리는 행위 | 0.5 |
| 나. 간이보관기구(비닐봉지, 천보자기 등)를 이용하여 폐기물을 버리는 행위 | 3 |
| 다. 휴식 또는 행락 중 발생한 쓰레기를 수거하지 아니한 경우 | 3 |
| 라. 차량, 손수레 등 별도 운반장비를 이용하여 폐기물을 버리는 행위 | 5 |
| 마. 사업활동과정에서 발생되는 폐기물(건축폐재류 등)을 버리는 행위 (「폐기물관리법」 제2조제3호에 따른 사업장폐기물 배출자, 같은 법 제25조에 따른 폐기물처리업자 및 같은 법 제46조에 따른 폐기 물재활용신고자가 사업장폐기물을 버리는 행위를 제외한다) | 15 |
