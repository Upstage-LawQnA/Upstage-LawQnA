# ○ 적용구분

- → ①은 직접복구비, ②는 감독업무비, ③은 간접복구비
- → 원인자복구 시 직접복구비 ①은 미징수
- → 원인자가 굴착영향구간을 전폭정비 시 ①+③은 미 징수


| 구분 | 복구비 부과 구분 | 복구자 | 비고 |
| --- | --- | --- | --- |
| A구간 | ① + ② + ③은 구기금으로 징수 | 자치구 | 보도 |
| B구간 | ① + ② + ③은 시기금으로 징수 | 도로 사업소 | 보도공사에 포함된 생활도로 나팔구진입 시도(차도) |
| C구간 | ① + ② + ③은 시기금으로 징수 | 도로 사업소 | 보도공사에 포함된 구도차도 진입 시도(차도) |
| D구간 | ① + ② + ③은 시기금으로 징수 | 도로 사업소 | 보도가 포함된 시도(차도) → 보도는 자치구에서 시도는 도로사업소에서 분리해서 복구 |
| E구간 | ① + ② + ③은 구기금으로 징수 | 자치구 | 시도(차도)에 포함된 보도 |
| F구간 | ① + ② + ③은 시기금으로 징수 | 도로 사업소 | 보도에 포함된 소규모 시도(차도) |
| G구간 | ① + ② + ③은 시기금으로 징수 | 도로 사업소 | 구도(차도)에 포함된 소규모 시도(차도) |
| H구간 | ① + ② + ③은 구기금으로 징수 | 자치구 | 시도(차도)에 포함된 소규모 구도 |
